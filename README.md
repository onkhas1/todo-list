# Список задач

Список дел со сроками. Задачи можно перетаскивать, а выполненная задача зачёркивается линией, как ручкой.

**Сайт:** https://onkhas1.github.io/todo-list/

## Что умеет

- добавлять задачи (кнопкой или клавишей Enter);
- отмечать выполненные и возвращать их в работу;
- удалять задачи; после удаления 5 секунд можно нажать «Вернуть»;
- сохранять список в браузере (localStorage), так что он остаётся после перезагрузки и закрытия вкладки;
- ставить задаче срок и, если нужно, точное время («сегодня в 18:30») в своём календаре и выборе времени, без системных окон браузера; просроченные подсвечиваются, их число видно в шапке;
- менять порядок: тянуть за точки слева, а с клавиатуры стрелками вверх и вниз;
- сортировать по сроку одной кнопкой: ближайшие дедлайны сверху, задачи без срока в конце;
- смотреть ближайшие 7 дней в ленте под датой: точки показывают, сколько дел на день, а нажатие на день оставляет в списке только его задачи;
- менять текст и срок двойным кликом или иконкой карандаша (Enter сохраняет, Esc отменяет);
- фильтровать задачи: все, в работе, готово, со счётчиком у каждого фильтра;
- убирать все выполненные одной кнопкой;
- синхронизировать список между открытыми вкладками.

Вёрстка рассчитана и на компьютер, и на телефон. С клавиатуры работает всё, у кнопок есть подписи для скринридеров. Если в системе включено «уменьшение движения», анимации отключаются.

## Как устроено

Обычные HTML, CSS и JavaScript, без фреймворков и сборки:

- `index.html` — разметка и шаблон строки задачи;
- `style.css` — оформление;
- `app.js` — логика: состояние, рендер, сохранение.

Чтобы запустить локально, откройте `index.html` в браузере.
