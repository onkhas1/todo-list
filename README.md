# Список задач

To-do list со сроками, сортировкой и перетаскиванием.

**Сайт:** https://onkhas1.github.io/todo-list/

## Функции

- добавление, отметка и удаление задач;
- сохранение в localStorage: список остаётся после перезагрузки;
- срок и время задачи, просроченные подсвечиваются;
- сортировка по сроку;
- перетаскивание мышью и пальцем, с клавиатуры — стрелками;
- лента ближайших 7 дней с фильтром по дню;
- фильтры «все / в работе / готово»;
- правка текста и срока;
- отмена удаления;
- синхронизация между вкладками.

Адаптивная вёрстка, управление с клавиатуры, учёт `prefers-reduced-motion`.

## Структура

HTML, CSS и JavaScript без фреймворков и сборки.

- `index.html` — разметка и шаблон задачи
- `style.css` — стили
- `app.js` — логика: состояние, рендер, сохранение

Запуск: открыть `index.html` в браузере.
